Cypher32

Install the firmware onto a Heltec Wireless Paper straight from this page. No toolchain, no command line — plug the board in over USB and press the button.

This browser cannot flash devices.

Flashing needs the Web Serial API, which today means Chrome, Edge or Opera on a desktop computer. Firefox and Safari do not implement it, and neither do phone or tablet browsers — including Chrome on Android and iOS.

Open this page on a laptop or desktop in Chrome or Edge, or flash from the command line with PlatformIO — see the README.

1 · Choose your range

Every device in one game must run the same profile. A different spreading factor or frequency is not a weak link — the radios simply cannot hear each other.

869.525 MHz and 22 dBm are legal in the EU (the ETSI g3 sub-band). If you are elsewhere, check your local rules before using LONG or EPIC — and build FAST from source on a frequency your region allows.

2 · Check the board

Before anything is written, read back what is actually on the other end of the cable. Nothing is flashed by this step — it only asks the chip what it is.

Make sure the antenna is attached before you power the board: transmitting into an empty connector can damage the radio.

Your browser asks which serial port to use. The board appears as a CP210x or USB Serial device. If nothing is listed, install the CP210x driver and reconnect. You will be asked to pick the port twice — once here, once to install — so choose the same one both times.

3 · Install

Check the board first. This is here so nobody writes Cypher32 over something that was never meant to receive it.
This browser cannot flash devices — see above. This page must be served over HTTPS to flash a device.

The installer script could not be loaded from the network. An ad blocker, a corporate proxy or an offline machine will all do this. Reload with the blocker off, or download the .bin from the build artifacts and flash it with esptool.

4 · First boot

  1. The screen shows a QR code and a Wi-Fi name like C32_XXXX.
  2. Scan it, or join that open network by hand.
  3. Your phone opens the portal automatically. If it does not, visit 192.168.4.1.
  4. Pick a faction and a password. That device is now yours.

What gets written

Flashing replaces everything on the board, including any saved game on it. Each image is the full layout — bootloader, partition table and application — so there is nothing else to install.
